# Squeezelite Home Assistant add-on repository

PulseAudio-only packaging for [upstream Squeezelite](https://github.com/ralph-irving/squeezelite),
with default AppArmor confinement and no privileged hardware access.

Add repository: `https://github.com/vectorcrumb/ha-addon-squeezelite`

See [setup and migration](squeezelite/DOCS.md) and [security review](SECURITY-REVIEW.md).
The numbered clone listings use the same implementation and allow independent
player instances; configure a distinct player name and identity for each.
